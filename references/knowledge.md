# 京东外卖红包助手 · 平台规则与叠加指南

> 覆盖平台：京东外卖、京东团购、京东到家（京东系本地生活）。
> 与通用外卖红包的差异：本技能聚焦**京东系**本地生活，核心是京东外卖新客专享、京东PLUS会员叠加、与京东到家/团购联动。

## 一、各板块红包规则

### 京东外卖
- **领取条件**：新客首单立减、老客外卖频道券、爆品低价活动
- **使用门槛**：限京东外卖订单，多为满减或立减券；部分券限品牌/品类
- **有效期**：券码多为当日或数天有效
- **是否可叠加**：券与店铺满减可叠；爆品低价商品不与大额券重复

### 京东团购
- **领取条件**：新客团购券、老客到店团购券，团购1折起
- **使用门槛**：限到店团购/本地生活券，多为指定套餐/项目
- **有效期**：券码7~30天
- **是否可叠加**：团购券为一口价，一般不与其他券叠加

### 京东到家
- **领取条件**：新客首单券、老客超市/医药/鲜花到家满减
- **使用门槛**：限京东到家商超/便利/药品订单，常见满减门槛
- **有效期**：券码数天有效
- **是否可叠加**：券与门店满减可叠，配送费另算

## 二、红包叠加逻辑

- **叠加顺序**：京东外卖/到家券 → 店铺满减 → 支付优惠（京东支付/银行卡）
- **PLUS会员叠加（核心差异）**：京东PLUS会员有专属外卖券、运费/权益，下单前在账号"PLUS中心"确认已领
- **京东账号打通**：外卖、到家、团购共用一个京东账号，券发到同一账号，跨板块联动
- **爆品/9.9包邮**：京东爆品双份低至9.9、9块9包邮频道为一口价，适合凑单

## 三、品类专属知识要点

### 3.1 京东外卖新客专享
- 京东外卖补贴期，**新客首单立减力度大**，是本技能最大的省钱点
- 新客限从未在京东下过外卖单的账号，用京东账号直接下单
- 新客券一个账号一次，用在第一次外卖首单最划算

### 3.2 与京东到家/京东团购联动
- **京东外卖**：餐品配送，券抵餐费
- **京东到家**：商超/药品/鲜花1小时达，满减券
- **京东团购**：到店餐饮/休闲券，到店核销
- 三者同属京东本地生活，用一个京东账号，券不通用但活动互通

### 3.3 PLUS会员叠加（差异化重点）
- 已是PLUS会员：在"PLUS中心"领专属外卖券、省运费，叠在外卖券上再省
- 非PLUS：先领新客外卖券下单，用得勤再考虑开PLUS
- PLUS专属券需主动领取，不是自动到账，下单前去账号里确认

### 3.4 与通用外卖红包的差异
- 本技能只导**京东系**外卖优惠，不导美团/饿了么通用券
- 用户主要在美团/饿了么点外卖→用通用外卖红包技能
- 用户是京东老用户、有PLUS、想试京东外卖→用本技能领京东专属新客券

## 四、新客与老客区别

- **新客专享**：京东外卖/到家首单大额立减，力度最大
- **老客可领**：外卖频道券、团购券、爆品低价活动
- **新老客通用**：京东本地生活通用券、PLUS专属券
- 京东外卖补贴期新客最香，老客靠频道券和PLUS叠加

## 五、避坑指南

1. **配送费不抵**：券抵商品款，配送费、打包费另算
2. **爆品一口价不叠券**：9.9爆品已是低价，不再叠大额券
3. **团购券到店核销**：注意营业时间、是否需预约、节假日是否可用
4. **券别领错号**：外卖/到家/团购共用京东账号，确认券在常用账号
5. **特殊品类**：药品、烟草按规定销售，部分不可用券或限购
